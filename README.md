# Digital Payment Data Platform

An end-to-end data engineering project that simulates a digital payment data platform.

## Objective

Build a reliable and scalable data pipeline for digital payment transaction data.

## Planned Components

- Python
- SQL
- PostgreSQL
- Docker
- Apache Airflow
- Google Cloud Storage
- BigQuery
- Data Quality Validation
- Pipeline Monitoring
- Automated Testing
- CI/CD
